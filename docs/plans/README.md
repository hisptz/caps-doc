## How to turn a plan into a page

1. Write the page under `src/content/docs/deployment-guide/` or `src/content/docs/development-guide/`. The sidebar is autogenerated from that folder (`src/tabs.ts`).
2. Keep the frontmatter shape already used on the guide index: `title`, `description`, and `sidebar.label` / `sidebar.order`.
3. Copy commands, image names, env vars, and button labels from the materials and screenshot plans. If a fact is marked **confirm**, check the source file in the same change and do not publish a guess.
4. Put images in `src/assets/deployment/` or `src/assets/development/` using the filenames in the screenshot plan. Do not commit screenshots that show real passwords, tokens, or patient data.
5. Leave this `docs/plans/` tree in place until the guide is written. Update a plan when a command or label changes, so the next page does not drift from caps-engine or caps-app.

The User Guide plan is not in this folder yet. Do not fold operator tasks into these two guides.
